StockBridge Chrome Extension 0.2.5

Extension ID: hbfdbpbfefkbpmljbfnhedljapnlbfhl

Requirements
------------
Chrome on Windows only accepts this private extension when the browser is
managed by Active Directory, Azure AD, or Chrome Enterprise Core. The registry
file alone will not install the extension on an unmanaged computer.

Optional installation
---------------------
1. IT adds the extension as Allow install and approves this install source:
   https://stockbridgedpp.vercel.app/*
2. Open https://stockbridgedpp.vercel.app/extension/install.html in the managed Chrome browser.
3. Click Install in Chrome and approve the extension prompt.
4. Remove the older unpacked StockBridge extension if it is still listed.

The registry file in this folder is an IT fallback for force installation. It
is not needed when Google Admin supplies the optional-install policy.

Updates
-------
Chrome checks https://stockbridgedpp.vercel.app/extension/updates.xml automatically. Future releases only require the
StockBridge publisher to increase the version and replace the hosted files.
