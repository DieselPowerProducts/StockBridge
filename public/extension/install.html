Installation

  1. Click Install in Chrome.
  2. Approve Chrome's extension prompt.
  3. Remove an older unpacked StockBridge copy if one is still listed.

If Chrome reports CRX_REQUIRED_PROOF_MISSING, the company installation policy has not reached this browser. Open chrome://policy, reload policies, and contact IT if the message remains.
